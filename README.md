# 📊 Dashboard de Análise de Tendências do YouTube

Dashboard interativo desenvolvido no Tableau Public para analisar padrões de vídeos em alta na plataforma, cruzando métricas de visualizações, curtidas e comentários por categoria e período.

## 🎯 Objetivo

Identificar tendências de engajamento que podem apoiar decisões de estratégia de conteúdo e publicação.

## 🚀 Tecnologias

- Tableau
- Tratamento e preparação de dados

## 📈 Dashboard

🔗 [Ver dashboard no Tableau Public](https://public.tableau.com/app/profile/everton.hernandez/vizzes)

## 🔍 O que o projeto mostra

- Volume de visualizações, curtidas e comentários por categoria
- Variação de tendências ao longo do período analisado
- Painel interativo com filtros por categoria e data

## 📝 Sobre o projeto

Projeto desenvolvido durante o bootcamp de Análise de Dados da [TripleTen](https://tripleten.com.br/).
